# Image licence ledger

One row per image on the site (and per Canva source asset). This is a handover record, not legal advice. Last updated 2026-11-19.

**Statement for the handover (do not put it on the public site):** AI-generated; no exclusivity or registrable copyright promised. Anyone can get similar results from similar prompts. The seller makes no promise that any image can be registered for copyright or that it is unique to this site.

The public site carries no visible AI wording on images. AI disclosure lives in the Editorial Standards page and in handover documents like this one. Invisible provenance metadata is embedded in the files (see below).

## Rules for adding a row
- Add a row the same day an image enters `src/assets/`. The test `src/test/image-ledger.test.ts` fails if a file in `src/assets/` has no row here.
- Fill every column. If a fact is unknown, write "not recorded", never a guess.
- AI-generated images: run `node scripts/embed-ai-metadata.mjs` after ingesting (the ingest script strips metadata), then `node scripts/embed-ai-metadata.mjs --check`.
- Stock photos (if ever used): record the licence text URL and the download date, and save a dated copy of the licence page with the sale papers.
- Amazon or brand images are never used.

## Embedded metadata (invisible)
- IPTC `DigitalSourceType` = `trainedAlgorithmicMedia` (http://cv.iptc.org/newscodes/digitalsourcetype/trainedAlgorithmicMedia).
- The 14 original images already carry it in their content credentials (C2PA) block, written by the generating tool. Their embedded record names the software agent as "gpt-image" and was written 2026-11-19; this is an observation of the file, not a statement we verified with the tool vendor.
- The 4 Canva images had metadata stripped on ingest, so the same field was added as an XMP packet by `scripts/embed-ai-metadata.mjs` (no dependencies, no pixel changes). Checked 2026-11-19: `node scripts/embed-ai-metadata.mjs --check` reports 0 files lacking it.
- Tools used to check: the script's own check, `strings`, and Python Pillow (`getxmp`). exiftool was not installed.
