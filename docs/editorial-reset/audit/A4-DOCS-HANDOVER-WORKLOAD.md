# A4 audit: docs, buyer handover package, owner workload, costs, assets

Status: READ-ONLY audit, 2026-11-19. Nothing in the repo was edited, moved, deleted, built or committed except this report. Measurements: `du`, `find`, `wc`, `md5sum`, and `node scripts/make-buyer-package.mjs --list` (a documented dry run that writes nothing). All minutes and hours in section 3 are ESTIMATES unless a document is cited; UNKNOWN means no source in the repo gives a number. No price in this file was invented: every price is cited to a doc and carries that doc's own confidence tag.

Plain rule used for classification:
- BUYER-ESSENTIAL: a new owner needs it to run, transfer, or make an informed decision.
- SELLER-PRIVATE: audits, review histories, handling logs, Cowork prompts, tracker packets, internal scores, pricing and negotiation papers. Kept (never destroyed) in a seller archive outside the buyer package. Anything in a private file that is a MATERIAL BUSINESS RISK or LIMITATION must be restated in the buyer package (section 2, doc 06b). Private never means concealed.
- DUPLICATE/STALE: superseded or repeated content; fold into one buyer doc, then archive the original.
