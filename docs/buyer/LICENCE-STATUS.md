# Licence status (for owner review)

**Not legal advice.** This records what is true today; it does not choose a licence.

## Where things stand

- **The project's own code and content carry no open-source licence.** None has been added, on purpose. Without a licence, copyright stays with the author and nobody else may copy, change or redistribute the code. Handing code to a buyer is done by a written transfer in the sale agreement, not by a licence file.
- `package.json` already says `"private": true` (npm will refuse to publish it) and `"license": "UNLICENSED"` (the npm convention for "no licence granted"). These were checked on 2026-11-19; nothing was changed for this note and tests and builds are unaffected. There is no `LICENSE` file in the repo.
- **Third-party packages keep their own licences.** `THIRD-PARTY-NOTICES.md` (generated by `node scripts/third-party-notices.mjs`) lists them. The production set is permissive (MIT, ISC, BSD, Apache-2.0, 0BSD, Unlicense, Python-2.0), plus MPL-2.0 for unmodified build tooling and CC-BY-4.0 for browser-support data. No GPL, AGPL or unknown licence was found at generation time.
- **Fonts** are under SIL OFL 1.1 (files in `design/brand/fonts`). **Images** are AI-generated with unverified commercial-use and transfer terms (`docs/buyer/IMAGE-AND-ASSET-RIGHTS.md`).

## Decisions that belong to the owner

1. **Who owns the work and in what form it passes to a buyer** (a written assignment of the code, articles, brand files and pin designs in the sale agreement; a lawyer should word it). Nothing in the repo is an assignment.
2. **Whether to keep "UNLICENSED"** (recommended while the code is for sale) **or choose a licence later.** Do not add an open-source licence to a repo that is being sold: it would let anyone use the code freely and could not be taken back for copies already made.
3. **Whether the repo stays public** (see `docs/buyer/REPO-VISIBILITY.md`). A public repo with no licence is still "all rights reserved", but anyone can read it and the copies already made.
4. **Whether to ship a notices file with the package.** `THIRD-PARTY-NOTICES.md` is listed in `docs/buyer/BUYER-PACKAGE-CONTENTS.md` as included.

## What this note does not cover

Trademarks (the name and logo are not registered or cleared), the legal pages (starter text), and the marketplace's own terms.
