# Start here (buyer)

Plans Past Five is a website for women who want hobbies, weekend plans and friendships outside work. It is **pre-revenue and not live on a real domain** as of 2026-11-19: no connected domain, no affiliate account, no analytics active (the GA4 setting is empty; see `docs/buyer/ANALYTICS-SETUP.md`), no email list, no traffic history. You are buying a built starter site and a plan, not an earning business. Nothing in these docs promises traffic, rankings or income.

Every count (articles, hobbies, products, kits, pins, images, tests, pages) is in `docs/buyer/INVENTORY.md`, generated by `node scripts/inventory.mjs`. No other document should repeat a number; if you find one, trust INVENTORY.md.

## What you receive

- The website source code, tests and CI files (TanStack Start, React, TypeScript, Tailwind; Bun is the package manager).
- The articles (published and outline drafts), hobby directory, shop collections, researched product records and starter kits, and the quiz, planner and budget tools.
- Brand files (logos, palette, templates), the Pinterest pin images with their CSV and 90-day plan, and the content and commerce research behind them.
- These guides, `THIRD-PARTY-NOTICES.md`, and the takeover notes in `docs/marketplace/final-inspection/BUYER-TAKEOVER.md`.

The exact list is `docs/buyer/BUYER-PACKAGE-CONTENTS.md`.

## What is excluded (you create or obtain it yourself)

- Every account: domain login, hosting, mailbox, Amazon Associates or any affiliate account, Google Analytics and Search Console, Pinterest, Canva, Lovable. Nothing transfers from the seller (`docs/buyer/ACCOUNT-DEPENDENCIES.md`). Whether the registered domain and mailbox are part of a sale is the seller's decision.
- Credentials, tax information, the seller's other businesses and personal data.
- Any traffic, revenue or ranking history: there is none.
- Rights beyond what is stated: the images are AI-generated with unverified commercial-use and transfer terms and no exclusivity (`docs/buyer/IMAGE-AND-ASSET-RIGHTS.md`); the code carries no open-source licence (`docs/buyer/LICENCE-STATUS.md`); the name and logo are not trademarked or cleared; the legal pages are starter text, not legal advice.

## Your first day

1. Put the code in your own GitHub account (`docs/buyer/TRANSFER-CHECKLIST.md`).
2. Install Bun and Node 22 (neither version is pinned in the repo).
3. `bun install --frozen-lockfile`, then `bun run dev` and open the address it prints (it binds to 127.0.0.1).
4. `bunx vitest run`, `bunx tsc --noEmit`, `bun run build`. Everything should pass.
5. Read `docs/buyer/BUSINESS-OVERVIEW.md` and the findings below. Then decide your hosting and domain (`docs/buyer/HOSTING-AND-DEPLOYMENT.md`: Netlify is configured, the site needs a server-rendering function, and nothing is verified on your own account yet).

What you can do alone and what needs a developer: the table in `docs/marketplace/final-inspection/BUYER-TAKEOVER.md`. The short version: articles in a browser once the editor is connected and tested; everything else needs a developer or an assistant for a few hours.

## Three findings from the takeover rehearsal

- **Dev server.** `bun run dev` runs `vite dev --host 127.0.0.1` (the old default failed without IPv6). Open the "Local:" address it prints.
- **The product importer replaces the whole catalog.** `bun run import:products <csv>` rebuilds the catalog from the file you give it. Start from the full `docs/commerce/product-research.csv`, run `--check` first; a guard refuses a write that shrinks the catalog by 30% or more unless you add `--force` (`docs/buyer/PRODUCT-MANAGEMENT.md`).
- **Publish gate.** The build refuses a published article with no source, no `verifiedAt` date or unresolved checks. That proves the fields exist, not that the facts are right: you still verify every claim (`docs/SOP-publish-article.md`). A saved edit is not a live edit: nothing goes live until you deploy on purpose (`docs/buyer/NETLIFY-CREDITS-AND-RELEASES.md`).

## What we do not claim

No traffic, no revenue, no approved affiliate account, no indexing before Search Console shows it, no exclusive or copyrighted images, no trademark clearance, no legal review, no no-code editing of hobbies, products or config (articles only, once the editor is connected and tested), and not live on a real domain until you deploy and check it. Facts that change (prices, plan limits, program rules) say "re-read live": check the official page before relying on them.
