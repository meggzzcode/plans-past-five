# Rule for every affiliate-ready project

1. Two resolvers, always: one monetizable (on-site buttons), one export (everything else).
2. The export resolver must not import the affiliate registry.
3. Copy, print, share, download, .txt/.json/code export and email text use the export resolver only.
4. Prefer names plus a link back to your own page over any retailer URL in offline material.
5. Never put a tag, ref=, linkCode or tracking param in exported text.
6. The affiliate statement appears only beside on-site links, never in exports.
7. Saved/exported data stores product ids, not URLs.
8. Tests run with the registry disabled and enabled and assert no tag in any export.
9. Re-read the network's current policies on offline use before going live; record date and quotes.
10. Keep internal research notes out of public components and test for forbidden phrases.
