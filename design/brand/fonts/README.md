# Brand fonts (local copies)

Static TrueType files downloaded from Google Fonts (latin subset, default optical size) so that logo builds, pins and templates render without network access.

| File(s) | Family | Used for | License |
|---|---|---|---|
| Fraunces-500/600/700 (+ italics) | Fraunces | Headlines, wordmark, expressive italics | SIL Open Font License 1.1, see OFL-Fraunces.txt |
| DMSans-400/500/700 | DM Sans | Body copy, UI, kickers | SIL OFL 1.1, see OFL-DMSans.txt |
| Caveat-500/700 | Caveat | Handwritten annotations (sparingly) | SIL OFL 1.1, see OFL-Caveat.txt |

The OFL permits commercial use, embedding and redistribution (including inside logo outlines and exported images). The fonts may not be sold on their own.

Note: the website loads the variable Fraunces from Google Fonts with the SOFT and WONK axes (SOFT 100, WONK 1). These static files are the default-axis instances, so letterforms in the SVG logos and pins are very slightly less soft than the live site wordmark. To match exactly, download the variable Fraunces and set SOFT=100, WONK=1 in your design tool.
