Before you buy anything

A tiny supply list is a kindness to your wallet and your future self. Run every purchase through these five questions.

the wishlist can wait

  1. Do I already own something that works? Pencils, scrap paper, old fabric and kitchen tools go a long way.
  2. Can I borrow or buy it used? Friends, community groups and secondhand shops are great for tools.
  3. Have I tried it twice? Wait for the second session before buying more than the basics.
  4. Does it solve a problem I actually had? Buy to fix a frustration, not to feel prepared.
  5. Can I wait a week? Put it on the wishlist. If you still want it, buy it.
This checklist names types of supplies, not brands. Check shops near you for what's available and sensible. We don't list prices because they change.

Starter lists: part one

Tick what you have. Circle what you'll start with. Cross out what can wait.

make, mess, repeat

Watercolor

Already at home

  • Any paper you own
  • A mug of water, an old towel

Start with

  • A small pan set
  • One round brush

Buy later, only if you love it

  • Good paper, extra brushes, masking fluid

First session: Paint a simple wash and three small shapes.

Junk journaling

Already at home

  • Scrap paper, envelopes, receipts
  • Glue stick, scissors

Start with

  • A notebook that can handle glue
  • Washi tape

Buy later, only if you love it

  • Stamps, stickers, fancy ephemera

First session: Fill one page with whatever's in your recycling.

Air-dry clay

Already at home

  • A smooth work surface
  • A bowl of water, a butter knife

Start with

  • One block of air-dry clay
  • A rolling pin you own

Buy later, only if you love it

  • Paints, sealers, tools

First session: Make a small trinket dish and let it dry overnight.

Embroidery

Already at home

  • A scrap of cotton fabric
  • Sharp scissors

Start with

  • A small hoop
  • Six-strand floss in 3 colors
  • Embroidery needles

Buy later, only if you love it

  • Patterns, more colors, fabric packs

First session: Stitch your initial in simple backstitch.

Notes: which one am I trying first, and when?

Starter lists: part two

Same rule: borrow, thrift, wait. Only the “start with” list is needed for session one.

tiny kits win

Bracelet making

Already at home

  • A flat table, tape
  • Scissors

Start with

  • A few bead colors
  • Stretch cord or string

Buy later, only if you love it

  • Charms, clasps, a bead storage box

First session: Make one bracelet for a friend.

Crochet

Already at home

  • Scissors
  • A blunt needle for ends

Start with

  • One hook in a mid size
  • One smooth cotton yarn

Buy later, only if you love it

  • Patterns, yarn bundles, stitch markers

First session: Make a small flat square, any wonky size.

Collage

Already at home

  • Magazines, old books, junk mail
  • Scissors, glue stick

Start with

  • A pad of heavy paper

Buy later, only if you love it

  • Specialty papers, craft knife, gel medium

First session: Cut thirty shapes and arrange them before gluing.

Hand lettering

Already at home

  • Any pencil, any paper

Start with

  • A fine felt-tip pen
  • A brush pen

Buy later, only if you love it

  • Guide sheets, ink, nibs

First session: Write the alphabet three ways.

Notes: what I already have that fits these
