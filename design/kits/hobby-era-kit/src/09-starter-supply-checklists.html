How to shop for a new hobby

A minimum kit makes it easy to begin. Everything else is a reward for sticking with it.

buy last

  1. Borrow or use what you own before buying anything.
  2. Buy the beginner basics. Skip the sets with fifty items.
  3. Do two sessions before you upgrade.
  4. Upgrade one thing at a time, the thing that annoyed you most.
Lists name types of supplies, not brands or prices. Check what's sensible where you live.

minimum kit

Watercolor

Already at home

  • Any paper you own
  • A mug of water, an old towel

Start with

  • A small pan set
  • One round brush

Buy later, only if you love it

  • Good paper, extra brushes, masking fluid

First session: Paint a simple wash and three small shapes.

Junk journaling

Already at home

  • Scrap paper, envelopes, receipts
  • Glue stick, scissors

Start with

  • A notebook that can handle glue
  • Washi tape

Buy later, only if you love it

  • Stamps, stickers, fancy ephemera

First session: Fill one page with whatever's in your recycling.

Air-dry clay

Already at home

  • A smooth work surface
  • A bowl of water, a butter knife

Start with

  • One block of air-dry clay
  • A rolling pin you own

Buy later, only if you love it

  • Paints, sealers, tools

First session: Make a small trinket dish and let it dry overnight.

Embroidery

Already at home

  • A scrap of cotton fabric
  • Sharp scissors

Start with

  • A small hoop
  • Six-strand floss in 3 colors
  • Embroidery needles

Buy later, only if you love it

  • Patterns, more colors, fabric packs

First session: Stitch your initial in simple backstitch.

minimum kit

Bracelet making

Already at home

  • A flat table, tape
  • Scissors

Start with

  • A few bead colors
  • Stretch cord or string

Buy later, only if you love it

  • Charms, clasps, a bead storage box

First session: Make one bracelet for a friend.

Crochet

Already at home

  • Scissors
  • A blunt needle for ends

Start with

  • One hook in a mid size
  • One smooth cotton yarn

Buy later, only if you love it

  • Patterns, yarn bundles, stitch markers

First session: Make a small flat square, any wonky size.

Collage

Already at home

  • Magazines, old books, junk mail
  • Scissors, glue stick

Start with

  • A pad of heavy paper

Buy later, only if you love it

  • Specialty papers, craft knife, gel medium

First session: Cut thirty shapes and arrange them before gluing.

Hand lettering

Already at home

  • Any pencil, any paper

Start with

  • A fine felt-tip pen
  • A brush pen

Buy later, only if you love it

  • Guide sheets, ink, nibs

First session: Write the alphabet three ways.

minimum kit

Pressed flowers

Already at home

  • Heavy books
  • Plain paper or paper towel

Start with

  • Blooms or leaves you've collected
  • A pad of blotting paper

Buy later, only if you love it

  • A flower press, glass frames

First session: Press three flowers and leave them for two weeks.

Sketching

Already at home

  • A pencil
  • Any paper

Start with

  • A small sketchbook
  • A soft pencil and an eraser

Buy later, only if you love it

  • Pens, charcoal, a sketching bag

First session: Draw five objects on your desk.

Zine making

Already at home

  • A sheet of printer paper
  • A pen, scissors

Start with

  • A stapler
  • A glue stick

Buy later, only if you love it

  • A guillotine cutter, special paper

First session: Fold one sheet into a tiny eight-page zine.

Macrame

Already at home

  • Scissors
  • A dowel, branch or spoon to hang from

Start with

  • Cotton cord
  • A ring or a stick

Buy later, only if you love it

  • A rack, different cords, beads

First session: Make a simple knotted keyring.
