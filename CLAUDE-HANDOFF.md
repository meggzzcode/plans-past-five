## How to…
- **Add an article:** copy a similar `content/articles/<slug>.json` (blocks: p, h2 with id, list, quote, image, item, inserts like `shopHobby`, `noSpend`, `makePlan`, `ifYouLoved`), keep `"status": "draft"`, run `bun run content:format <file>` then `bun run content:build`. The build writes `src/content/generated/`; do not edit that by hand. `status: "draft"` keeps it out of routes, lists, search and sitemap. Inline text supports `**bold**` and `[link](/path)`.
- **Publish a draft:** write its `body`, add `sources`, `verifiedAt` and `publishedAt`, resolve every `coworkChecks` item, set `status: "published"`. The build refuses a published article without sources, `verifiedAt` or with open checks.
- **Add/edit products:** researched products come from `docs/commerce/product-research.csv` via `bun run import:products <csv> --check` then the same without `--check`; **the importer replaces the whole generated catalog**, so start from the full CSV. Product types (search-link cards) are in `src/data/products.ts`. Never add prices, ratings or ASINs without verification.
- **Monetize:** only with the buyer's own approved Associates account: set the Amazon entry in `src/config/affiliate.ts` (tag, `approved`, `active`); see `docs/buyer/AFFILIATE-ACTIVATION.md`. Several tests assert the unmonetized default and must be updated.
- **Hobbies:** `src/data/hobbies.ts` seeds; tags (at-home, after-work, low-cost…) are derived in `make()`.
- **Quiz matching:** `src/lib/finder.ts` — hard filters (location, time, budget, company, energy ≤ +1), score craving +4, energy +2, beginner +1; theme from top categories; <3 results → suggests which constraint to loosen.
- **Planner:** `src/lib/planner.ts` + `src/data/activities.ts` — slots by when/length, filters part/company/budget/minutes/at-home, vibe score, `seed` rotates within top 4 (Shuffle). Activities never name real places, events or prices.
- **Saved items:** `src/lib/saved.ts`, key `ppf:my-plans:v1` in localStorage, read after mount.
- **Analytics:** no newsletter is planned (the `site.integrations.newsletter` flag is an unused placeholder). Analytics is wired but off: set `analytics.ga4MeasurementId` (empty by default) to load GA4; decide consent first (`docs/buyer/ANALYTICS-SETUP.md`).

## Turnkey build-out (2026-11-19, branch claude/vibrant-dirac-amdf7r)
Buyer docs: `docs/buyer/`. Content and commerce docs: `docs/content/`, `docs/commerce/`, `docs/marketing/`.
- **Articles:** the published ones (count: INVENTORY.md) are `status: "published"` and registered in `src/content/index.ts`. Drafts and outline-only entries (`src/content/drafts.ts`) are registered in `src/content/draft-registry.ts`, which only tests and scripts import, so draft text is not bundled into the public site. Source-check records are in `docs/content/verification/` and `docs/content/verification-applied/`. Published means set to published on the branch, not deployed.
- **Affiliate behavior changed:** setting `associatesTag` alone no longer monetizes. The Amazon entry in `src/config/affiliate.ts` must also be `approved` and `active`. See `docs/buyer/AFFILIATE-ACTIVATION.md`. The older "Monetize" note above is superseded.
- **Shoppable system:** `src/data/catalog.ts` and generated `src/data/catalog.generated.ts` (record counts: INVENTORY.md; imported with `bun run import:products`, which replaces the whole catalog; details in `docs/commerce/IMPORT-REVIEW.md`), `src/components/commerce/*`, `src/lib/shoplist.ts`. Only verified records render, and with no verified product a slot renders nothing. Verified means the Amazon listing was checked (ordinary non-affiliate links), not that the product was tested.
- **Planner and quiz** were rewritten (total budget, time slots, restoring saved plans, energy, quiz handoff). New tools at `/tools/hobby-budget` and `/tools/tonight`.
- **Trust pages:** `/editorial-policy` (with the one AI disclosure), `/methodology`, `/corrections`.
- No newsletter, printables, digital products, downloads or calendar files: removed or never built, by owner decision (2026-11-19). `src/test/no-printables.test.ts` guards this.
- Amazon Associates is the only affiliate program; nothing is applied for or active. Hosting: Netlify is configured (`netlify.toml`); one test deploy ran on the seller's own Netlify account and is not transferred; nothing is live on a real domain.
